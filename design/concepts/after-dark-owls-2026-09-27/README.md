# After-dark carousel with owl artwork

Three visual concepts generated with the built-in image generation tool on 27 September 2026. The approved direction is an hourly three-page carousel: two bat graph pages with a persistent illustrated owl panel, and an owl-led field-journal page when an owl has been heard that night. These files are concept previews, not implementation or hardware validation.

## Pages

- 01-night-rhythm-with-owl.png: bat activity profile and separate owl occurrence lane; illustrated Owls tonight panel.
- 02-seven-nights-with-owl.png: comparable four-hour bat activity windows over seven dates, separate owl occurrence column; illustrated Owls tonight panel.
- 03-owl-field-journal.png: large tawny owl illustration with historical acoustic-identification details and supporting bat activity chart.

All observation data and times are invented and visibly labelled. The same sample evening is used throughout: four bat activity-minute bins of 12, 23, 17, 8; three qualifying tawny-owl records in the 2–3 hour bin, last at 9.18pm BST. Activity minutes and detection records are different units, neither is an animal count. Seven-night owl marks appear on 23, 25 and 27 September. Historical baselines and monitoring completeness are assumed for these sample concepts only.

The previous concepts were edit targets for typography/layout, not chained illustration references. The original art_studio/reference/robin.png remains the sole art style reference. Owl illustrations are AI-generated concept artwork, not approved replacements for the existing curated collection. No station, services, application code, credentials or paid-generation ledgers were accessed or changed for this render task.

The images were visually inspected for layout, text and observation semantics. Production work still needs deterministic charts, shared approved owl artwork, actual 480×800 rendering/palette checks and physical readability verification.
