# After-dark design concepts

Created 27 September 2026 with the built-in image generation tool. These are AI-generated visual targets with invented sample data, not actual Garden Ink renderer output or hardware-tested layouts. The portrait compositions target the 480 × 800 screen's 3:5 proportions. Bat artwork is concept art, not an anatomy-approved production asset.

1. 01-night-rhythm.png — hourly activity compared with recent-night median.
2. 02-seven-nights.png — same four-hour period across seven evenings.
3. 03-bat-field-journal.png — educational species spotlight with generic recorded activity.

References: design/previews/v2.1/no_clock.png for screen layout; art_studio/reference/robin.png is the sole original illustration style reference. No paid API key or artwork-generation ledger was used.

All counts and times are invented. The activity unit means one-minute bins containing a qualifying detection, not individual bats or continuous calling duration. Species spotlight content does not establish local species identification.
