Optional local artwork replacements
==================================
Use a PNG named after the exact scientific name, lower case and spaces replaced
with underscores. For example:
  erithacus_rubecula.png
  passer_domesticus.png

Prefer a white or transparent background, a complete bird and no text.
Keep the image below 12 megapixels. Restart the application after adding it.
A custom file takes precedence over a bundled image for the same species.
No image is downloaded at runtime, and no unrelated bird is used as fallback.
