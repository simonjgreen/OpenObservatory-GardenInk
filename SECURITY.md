# Security and privacy

Do not post credentials, station addresses, coordinates, recordings, private logs or state databases in public issues. Keep site configuration, `.secrets/`, studio output and Pi runtime state outside Git.

Report vulnerabilities through this repository's GitHub **Security → Report a vulnerability** option when available. If unavailable, open an issue requesting a private reporting channel without disclosing the vulnerability or sensitive material.

The display reads a local Open Observatory station. Optional image generation sends the reference image, species identity and artistic instructions to OpenAI only after opt-in. See [automatic artwork](docs/operations/AUTOART.md) for data flow and spending controls.
